# **SeedTools Ransomware History Exhibit (v1.0 Enterprise)**

## 🎯 Purpose
The SeedTools Ransomware History Exhibit is a **public, educational, and technical collection of historical encryption incidents**, presented securely, following forensic and deterministic principles.
The exhibit shows:

- what real encryption looks like,
- how files behave after the incident,
- what ransomware extensions look like,
- what ransom notes look like,
- what the directory structure looks like after the attack,
- what a deterministic encryption pattern looks like.

This is a **truth gallery**, but without private data.

---

# 🔵 1. Exhibit Scope

The exhibit includes:

- historical ransomware incidents,
- technical examples of encrypted files,
- extensions used by the malware,
- excerpts from ransom notes,
- post-incident directory structures,
- technical metadata,
- deterministic encryption patterns.

The exhibit **does not include**:

- private photos,
- private documents,
- personal data,
- sensitive content.

--

The exhibit divides incidents into:

### **B. Modern Ransomware (2016–2020)**

### **C. Enterprise Ransomware (2020–2026)**
- REvil

Each category has:

- technical description,
- extensions,
- behavior,
- directory structure,
- deterministic elements.

# 🔵 5. Exhibit Format

Each exhibit has the following format:

```
Exhibit ID: RX‑###
Name: <Incident Name>
Year: <Year>
Family: <Ransomware Family>
Extensions: <List of Extensions>
Ransom Note: <Fragment>
Deterministic Behavior: <Description>
Directory Structure: <Example>
Metadata: <Description>
```

Example:

```
Exhibit ID: RX‑001
Name: CTB Locker — Historical Disk
Year: 2015
Family: CTB‑Locker
Extensions: .pcxypkn, .pcxykpn
Ransom Note: "Decrypt All Files"
Deterministic Behavior: Extension pattern + Preserved Timestamps
Directory Structure: Photos 2009–2015, Adobe Reader, Certificates
Metadata: NTFS timestamps preserved
```
