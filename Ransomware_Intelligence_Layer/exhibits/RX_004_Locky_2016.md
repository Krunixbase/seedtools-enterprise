# **RX_004 — Locky (2016)**
*(SeedTools Ransomware History Exhibit — v1.0 Enterprise)*

## 🎯 Exhibit Purpose
RX‑004 presents the **global Locky encryption incident of 2016**, which was one of the most widespread and effective ransomware in history.
The exhibit demonstrates:

- Massive spam campaigns with DOC attachments + macros,
- Automatic malware download after running a macro,
- File encryption using AES‑128 + RSA‑2048,
- Extension renaming to `.locky`,
- Aggressive propagation via the Necurs botnet,
- Deterministic Locky encryption patterns.

Locky was the **most widespread ransomware of 2016**—which is why it is the fourth exhibit in the SeedTools Exhibit.

## 🔵 2. Ransomware Extensions

Locky used a distinctive extension:

```
.locky
```

and later variants:

```
.osiris
.zepto
.aesir
```

Each variant was part of a successive wave of the campaign.

---

## 🔵 3. Ransom note

Excerpt from the original message:

```
All your files are encrypted with RSA-2048 and AES-128.
To restore your files, you must purchase the private key.
Instructions are provided in _HELP_instructions.html
```

Features:

- HTML + BMP + TXT files,
- professional layout,
- Bitcoin payment instructions,
- unique victim ID,
- links to Tor websites.

Locky was the first ransomware that:

- used the **Necurs botnet** for mass distribution,
- infected millions of devices within days,
- used **Word macros** as the main attack vector.

---

## 🔵 4. Directory structure after the incident

Locky:

- changed file extensions to `.locky`,
- did not change file names,
- did not change directory structure,
- added instruction files to multiple directories,
- encrypted files in place.

Examples of encrypted file types:

### 📁 Documents
- DOCX
- XLSX
- PPTX
- PDF

### 📁 Photos
- JPG
- PNG
- BMP

### 📁 Archives

- RAR
- 7Z

### 📁 Application Files
- DB
- PST
- Program Configurations

## 🔵 5. Deterministic Behavior of Locky

Locky demonstrates:

- deterministic AES‑128 + RSA‑2048 encryption scheme,
- deterministic file type selection,
- deterministic ransom note creation method,
- deterministic communication method with C2,
- deterministic infection method (macros + Necurs).

Locky was the first ransomware that:

- used **Word macros** as its main vector,
- used the **Necurs botnet** for global distribution,
- infected systems in the millions.
