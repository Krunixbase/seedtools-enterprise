# **RX_001 — CTB Locker (FA‑001)**
*(SeedTools Ransomware History Exhibit — v1.0 Enterprise)*

## 🎯 Exhibit Purpose
RX‑001 presents the **historical CTB‑Locker encryption incident from 2015**, preserved as a complete forensic artifact FA‑001.
The exhibit shows:

- real ransomware extensions,
- real malware behavior,
- real NTFS metadata,
- real directory structures after the incident,
- deterministic encryption patterns,
- fragments of the ransom note,
- technical impact of the attack.

This is the **first exhibit in the history of the SeedTools Ransomware Museum**.

## 🔵 2. Ransomware Extensions

CTB‑Locker used the following extensions:

```
.pcxypkn
.pcxykpn
.pcxy pkn (variant)
```

All extensions are:

- deterministic,
- uniform throughout the incident,
- applied to files from multiple years,
- Applied to files of various types.

## 🔵 3. Ransom note

Excerpt:

```
Decrypt All Files pcxypkn.TXT
```

Characteristics:

- text file,
- created deterministically,
- placed in multiple directories,
- preserved in its original form.
