---

## 🎯 Cel  
Zapewnić spójny, profesjonalny, deterministyczny standard dokumentacji dla wszystkich repozytoriów SeedTools.

---

## 🔵 1. Język dokumentacji

### **Primary Language: EN (English)**  
Wszystkie oficjalne dokumenty SeedTools muszą być w języku angielskim:

- dokumentacja techniczna  
- standardy  
- workflow’y  
- CI/CD  
- audit  
- release  
- README  
- PDF  
- prezentacje  
- grant submissions  

**Powód:**  
SeedTools jest projektem globalnym, open‑source, audytowalnym i grantowym.

### **Secondary Language: PL (Polish)**  
Dokumentacja w języku polskim jest opcjonalna i pełni funkcję:

- pomocniczą,  
- edukacyjną,  
- wyjaśniającą,  
- ułatwiającą zrozumienie technicznych aspektów.

---

## 🔵 2. Struktura dokumentacji

Każde repo SeedTools musi mieć:

- `/docs` — dokumentacja techniczna  
- `/standards` — standardy SeedTools  
- `/workflows` — workflow’y deterministyczne  
- `/pdf` — wersje PDF  
- `/examples` — przykłady  
- `/README.md` — główny opis repo  

---

## 🔵 3. Format dokumentów

### Markdown (MD)
- główny format  
- łatwy do audytu  
- łatwy do CI/CD  
- łatwy do konwersji do PDF  
- łatwy do publikacji na GitHub

### PDF
- wersja finalna  
- wersja do grantów  
- wersja do audytów  
- wersja do prezentacji
