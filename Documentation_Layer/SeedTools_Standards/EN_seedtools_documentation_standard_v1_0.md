```
SeedTools_Standards/PL_seedtools_documentation_standard.md
```

---

## 🎯 Goal
To ensure a consistent, professional, and deterministic documentation standard for all SeedTools repositories.

---

## 🔵 1. Documentation Language

### **Primary Language: EN (English)**
All official SeedTools documents must be in English:

- technical documentation
- standards
- workflows
- CI/CD
- audit
- release
- README
- PDF
- presentations
- grant submissions

**Reason:**
SeedTools is a global, open‑source, auditable, and grant-supported project.

### **Secondary Language: PL (Polish)**
Documentation in Polish is optional and serves the following purposes:

- supporting,
- educational,
- explanatory,
- facilitating the understanding of technical aspects.

---

## 🔵 2. Documentation Structure

Every SeedTools repo must have:

- `/docs` — technical documentation
- `/standards` — SeedTools standards
- `/workflows` — deterministic workflows
- `/pdf` — PDF versions
- `/examples` — examples
- `/README.md` — main repo description

---

## 🔵 3. Document Format

### Markdown (MD)
- main format
- easy for auditing
- easy for CI/CD
- easy to convert to PDF
- easy to publish on GitHub

### PDF
- final version
- grant version
- audit version
- presentation version
